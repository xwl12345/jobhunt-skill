# 首次初始化指引（流程 0 详细版）

目标：用最少的来回问出足够做方向规划的信息。分 4 批收集，每批 3–6 个问题：宿主提供结构化提问工具时可以借助，否则直接用自然对话分批提问，效果等价；用户主动陈述时先听完，再对照清单补缺口。整个收集与分析阶段不写任何文件，方案经用户确认后再动手。

## 一、信息收集清单（4 批）

### 第 1 批：基本情况与学历

- 姓名、联系方式（手机 / 邮箱，写简历用）。
- 学校、专业、学历层次（本科 / 硕士 / 博士）、入学与毕业年份（定届别和求职窗口）。
- 成绩排名 / GPA（若有优势）、获奖、英语水平（四六级 / 雅思）。
- 是否有升学或考公等备选路径（影响投入度判断）。

> 学历信息决定哪些公司有硬门槛（如部分大厂卡 211/985、部分岗位卡硕士），是三线划分的第一依据。

### 第 2 批：技能盘点（要真实水平，不要自我美化）

- 主力语言及熟练度：读过什么书 / 写过多大规模代码 / 是否在工作中用。
- 框架与工具：列出会用什么，逐个问"上一次用它做东西是什么时候、做了什么"。
- 计算机/专业基础自评：数据结构与算法（刷题量）、操作系统、网络、数据库。
- 证书、竞赛、开源贡献（若有）。

> 目的是产出"技能-真实水平-简历措辞"三列表的初稿，措辞分熟悉 / 了解 / 学习中三档，宁低勿高——面试官按简历措辞的深度提问。

### 第 3 批：实习与项目经历深挖（STAR）

每段经历问清：

- **S/T**：背景与你的任务，你是主导还是参与， mentor 布置还是自发。
- **A**：技术方案的关键决策点，为什么这么做。
- **R**：**可验证的真实成果**——commit 数、测试数、上线情况、导师评价；没有量化数据就不写量化数据。
- **边界**：哪些内容受保密限制不能公开 / 不能写简历；哪些项目在公开仓库有链接可挂。
- 每段经历问一句："面试官如果追问到底，哪里你最没把握？"——这是待补强清单的种子。

> 同时记录口径问题：每个项目的来源与真实角色（课程设计 / 自学练习 / 实习任务 / AI 辅助的毕业设计），面试口径必须与事实一致，二次开发的绝不写成原创。

### 第 4 批：意向与约束

- 意向岗位（可多个）、意向城市、可接受的范围。
- 求职时间窗口：秋招（应届主要窗口，一般毕业前一年 8–12 月）/ 春招（次年 3–5 月）/ 社招。
- 约束：是否必须拿 offer 保底（经济压力）、每周可投入准备的时间、是否有论文/毕设压力。
- 兴趣偏好：想做什么方向，不想做什么方向。

## 二、方向可行性分析框架

对每个候选方向按 5 个维度评估，1–5 分，写进规划里给用户看依据：

| 维度 | 判断什么 | 主要证据 |
|---|---|---|
| 学历门槛 | 该方向主流公司是否有院校/学历硬卡 | 第 1 批信息 + 当年招聘公告 |
| 技能匹配 | 岗位 JD 要求 vs 现有技能的重合度 | 第 2 批信息 + 搜 5–10 条真实 JD |
| 项目支撑 | 有没有能写上简历、面试能讲的对应项目 | 第 3 批信息 |
| 市场供需 | 该方向当年坑位数量与竞争密度 | 联网搜索当年行情，不凭旧印象 |
| 时间窗口 | 来不来得及准备到可投状态 | 第 4 批信息 + 补短板所需时间 |

**三线划分规则**：

- **保底线** = 学历门槛过得去 + 技能匹配 ≥3 分 + 已有项目支撑。大概率拿 offer，用于兜底。
- **主攻线** = 匹配度最高的 1–2 个方向，秋招 70% 投递精力放这里。
- **冲刺线** = 匹配度 2–3 分但兴趣高/待遇好，明确列出"补什么短板才有机会"（如：需要 1 个可展示项目 / 需要刷题到 X 题），够不着的就明说够不着。

**输出格式**（在计划里呈现给用户确认）：

```
## 方向规划建议
### 保底线：{{方向}}
- 理由：…（5 维度里最强的 2 项）
- 目标公司类型：…
- 简历版本：V1 保底版
### 主攻线：{{方向}}
- …
### 冲刺线：{{方向}}（需先补：…）
- …
### 未来 2–4 周行动建议
1. …（具体到可执行）
```

## 三、初始化产物清单

用户确认方向后，从 `assets/` 模板生成（填充信息，不是盲拷贝）：

1. `AGENTS.md` —— 概况（用户/届别/三线方向）、文件地图、硬规矩。
2. `个人档案.md` —— §0 统一口径与数据红线（把收集到的口径问题写进去）、§1 教育与技能三列表、§2 每段经历的 STAR、§3 待补强（第 3 批的"没把握"种子）。
3. `投递跟踪.md` —— 招聘窗口（按届别算）、目标公司三线清单初稿（可留待补）、空投递表。
4. `进度与薄弱点.md` —— **按方向定制**学习模块：保底/主攻方向对应的技术栈各一节 + 通用模块（算法刷题、面试八股），任务清单放进行动建议。
5. `简历/{{姓名}}-{{岗位}}-{{年份}}.md` 与 `.html` —— V1 初稿（信息够就出完整版，不够出骨架标 TODO）。
6. `.gitignore`（来自 gitignore.tpl）。

随后做版本化（按 SKILL.md「git 缺失处理」）：`git --version` 可用则 `git init` + 首次提交，并提醒远端必须私有；git 不可用且用户选择不安装时，做一份带日期的初始手动备份，在 AGENTS.md 标注"未启用 git"，不得假装已提交。
